# Jack the Bean Climber

Welcome to **Jack the Bean Climber**, a fantasy action-adventure game inspired by the classic fairy tale *Jack and the Beanstalk*!

Enter a gigantic tree tower, face the mighty Giant.

## About the Game

Jack the Bean Climber is an action-adventure game where you venture into a massive tree tower filled with dangerous monsters.

Your goal is simple: Take on the Giant waiting at the top!

## Requirements

Make sure you have the necessary game files and dependencies installed to run the game.

## Instructions

If not already installed, extract the Runtime Package for RPG Maker.

Run the game's executable. This will create a folder containing the game and its source code.

Once everything is ready, launch the game and begin your adventure!

## Controls

Alt + Enter = fullscreen to make game go biiiiig  
up arrow key to move up  
down arrow key to move down  
right arrow key to move right  
left arrow key to move left  
Enter/Space to confirm
